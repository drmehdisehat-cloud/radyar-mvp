# برش مستقل پیش‌نمایش دادیار

این شاخه از `main` ساخته شده تا فقط بسته عمومی پیش‌نمایش، آزمون‌های مرتبط و گردش‌کار read-only در یک تغییر کوچک و قابل بازبینی ارائه شود.

## دامنه
- تنها صفحه عمومی: `dadyar-preview/index.html`؛ سند خودبسنده و آفلاین.
- ورودی پرسش آزاد فارسی؛ طبقه‌بندی محلی و چندموضوعی با ۲۷ سرنخ داخلی.
- دامنه عملی این نسخه فقط کارگاه چک فرضی است؛ پرسش‌های خارج از دامنه تحلیل نمی‌شوند.
- سناریو فقط از داده ساختگی استفاده می‌کند.
- گزارش فقط پس از تکمیل چک‌لیست و ثبت تأیید محلی قابل دریافت است؛ رد بازبینی باید دریافت را مسدود کند.
- نقش‌های وکیل، قاضی، دادستان، ضابط و سردفتر صرفاً شبیه‌سازی آموزشی‌اند.

## کنترل‌های CI
- آزمون مرز آفلاین و CSP.
- آزمون کشف چندموضوعی ۲۷ حوزه و جلوگیری از نمایش برچسب‌های داخلی.
- آزمون Chromium در viewport باریک.
- آزمون Chromium با emulation موبایل و HTTP دقیق `/dadyar-preview/`.
- ثبت SHA-256 و Git Blob SHA فایل عمومی در `INTEGRITY.json`.
- Artifact فقط شامل `index.html` و `INTEGRITY.json` است.
- اسکریپت `scripts/probe-preview-staging-http.cjs` فقط‌خواندنی است و HTTPS، هدرهای امنیتی و برابری بایت‌به‌بایت این دو فایل را در مقصد staging بررسی می‌کند؛ خروجی آن مجوز انتشار نیست.

## مرز انتشار
این شاخه و Artifact صرفاً برای بازبینی‌اند؛ Workflow هیچ استقرار یا اتصال به هاست انجام نمی‌دهد.

- API و گفت‌وگوی هوشمند عمومی خاموش‌اند.
- هویت بازبین در صفحه آفلاین احراز نمی‌شود؛ اظهار محلی معادل تأیید مستقل نیست.
- هیچ منبع حقوقی در این برش برای نتیجه‌گیری قطعی تأیید نشده است.
- `backupRestoreVerified=false`، `destinationVerified=false` و `deploymentAuthorized=false` باقی می‌مانند.
- بکاپ واقعی باید در Sandbox مستقل خارج از Document Root تولید بازیابی شود؛ گزارش Restore، هش آرشیو و نشانگر بازیابی، probe دیتابیس، مسیرهای canonical و دو امضای مستقل لازم است.
- مقصد staging باید جدا از Git checkout و Document Root تولید باشد و پس از بارگذاری آزمایشی با SHA-256 و Git Blob SHA اعتبارسنجی شود.
- هیچ تغییری در `main`، DNS، فایل‌های اصلی سایت یا دیتابیس تولید مجاز نیست.

## دستور آزمون محلی

```sh
node --test tests/dadyar-preview-offline-boundary.test.cjs tests/dadyar-preview-27-domain-routing.test.cjs
CHROME_BIN=/path/to/chromium node --test tests/dadyar-preview-mobile-chromium.test.cjs tests/dadyar-preview-mobile-device-emulation.test.cjs
```

موفقیت این آزمون‌ها صرفاً صحت بسته آزمایشی را نشان می‌دهد و به‌تنهایی مجوز انتشار نیست.
