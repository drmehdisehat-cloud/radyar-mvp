# همراه شناور دادیار

این جزء مستقل فعلاً فقط معرفی و دسترسی به پیش‌نمایش است؛ API متصل نیست و پاسخ خودکار تولید نمی‌کند. شخصیت تصویر موجود مالک را با حرکت ملایم CSS نمایش می‌دهد؛ انیمیشن چهره، لب‌خوانی یا انسان سه‌بعدی ریگ‌شده نیست.

نصب روی ایران‌هاست پس از ورود مجدد و تهیه کپی برابر از نسخه فعلی صفحه: دو فایل JS/CSS این پوشه را کنار تصویر موجود `dadyar-mehdi-avatar-v1.png` در ریشه عمومی قرار دهید و قبل از بسته‌شدن body فقط این تگ را اضافه کنید:

```html
<script defer src="/dadyar-widget.js"></script>
```

حباب معرفی هنگام ورود ظاهر می‌شود؛ دکمه شخصیت پنل راهنما را باز می‌کند. خروج با Escape، بستن معرفی، توقف حرکت و prefers-reduced-motion پشتیبانی شده است. داده‌ای ذخیره یا ارسال نمی‌شود. Shadow DOM برای جلوگیری از تداخل سبک‌های سایت استفاده شده است. در صفحه دادیار همراه قدیمی همزمان نمایش داده نشود. مسیرهای contact و dadyar را در نسخه زنده بررسی کنید. CSS/JS باید طبق CSP همان دامنه مجاز باشند؛ CSP سایت را ضعیف نکنید.

تا این جزء روی هاست نصب و در مرورگر موبایل و دسکتاپ آزموده نشده، ادعای انتشار یا نمایش زنده نکنید. برای فعال‌سازی گفتگو، backend محافظت‌شده و حساب API دارای اعتبار و منبع حقوقی بازبینی‌شده لازم است.
