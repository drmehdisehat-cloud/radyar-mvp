# دادیار | Radyar MVP

**وضعیت: نمونه آزمایشی؛ برای اطلاعات واقعی موکل یا انتشار عمومی مجاز نیست.**

این مخزن ابزار مصاحبه و سامان‌دهی اولیه اطلاعات است؛ نه سامانه مشاوره حقوقی قابل اتکا، نه دادگاه مجازی عملیاتی و نه موتور متصل به بانک رسمی قوانین. خروجی آن تشخیص قطعی عنوان دعوا، صلاحیت، مهلت قانونی یا نتیجه پرونده نیست.

## آنچه واقعاً در شاخه آزمایشی وجود دارد

- شش جریان ساختاریافته فاز اول: سرقت تعزیری/زورگیری، ادعای کلاهبرداری، مطالبه وجه غیرچکی، چک، طلاق و مهریه.
- پیش‌نمایش مستقل در `dadyar-preview/index.html`: سناریوی کاملاً ساختگی چک، ورودی آزاد فارسی و تولید گزارش آموزشی در همان مرورگر.
- در پیش‌نمایش، ۲۷ حوزه حقوقی فقط به‌صورت **سرنخ‌های کلیدواژه‌ای داخلی** برای دسته‌بندی احتمالی سؤال آزاد استفاده می‌شوند. یک سؤال می‌تواند چند حوزه را فعال کند؛ انتخاب حوزه به کاربر تحمیل نمی‌شود. این ۲۷ سرنخ، ۲۷ ماژول حقوقی کامل یا منبع قانون نیستند و به‌تنهایی صلاحیت، عنوان دعوا یا نتیجه حقوقی را تعیین نمی‌کنند.
- متن خام سؤال آزاد در گزارش آموزشی درج نمی‌شود. این حذف و فیلترهای شناسه، تضمین ناشناس‌سازی یا مجوز ورود اطلاعات واقعی نیستند.
- نقش‌های وکیل، قاضی، دادستان، ضابط و سردفتر در پیش‌نمایش صرفاً شبیه‌سازی‌اند و هیچ سمت یا اختیار واقعی ایجاد نمی‌کنند.
- بازبینی داخل پیش‌نمایش فقط **اظهار محلیِ بدون احراز هویت** است. نام/برچسب، تصمیم و زمان دستگاه هویت بازبین، صلاحیت حرفه‌ای، امضای معتبر یا مهر زمانی قابل اتکا را اثبات نمی‌کند. این اظهار فقط جریان دانلود آموزشی را نمایش می‌دهد و جایگزین بازبینی مستقل و احراز‌شده نیست.

## مرز شبکه و API

### پیش‌نمایش آفلاین

فایل `dadyar-preview/index.html` مستقل از API است. سیاست CSP آن `connect-src 'none'` و `form-action 'none'` است؛ هیچ درخواست شبکه‌ای برای تولید گزارش لازم نیست. آزمون‌های ایستا و مرورگری باید این مرز را حفظ کنند. این فایل تا عبور از دروازه‌های انتشار، نباید روی سایت عمومی قرار گیرد.

### API توسعه محلی

`backend/server.js` یک سرویس توسعه‌ای است و فقط در حالت `NODE_ENV` خالی یا دقیقاً `development` اجازه اجرا می‌دهد؛ listener آن به loopback محدود است و برای اینترنت، reverse proxy یا هاست تولیدی طراحی نشده است.

- `POST /api/cases/validate`: اعتبارسنجی ساختاری داده؛ پرونده را ذخیره نمی‌کند.
- `POST /api/chat`: مسیر آزمایشی جداگانه است. فقط با Bearer token پیکربندی‌شده در `DADYAR_PREVIEW_TOKEN` و `OPENAI_API_KEY` می‌تواند به OpenAI درخواست بفرستد. این مسیر در پیش‌نمایش استاتیک استفاده نمی‌شود، به منبع رسمی قوانین متصل نیست و پاسخ آن تأیید حقوقی محسوب نمی‌شود.
- مسیر چت، احراز هویت عمومی یا معماری نشست امنِ آماده انتشار نیست. وجود کد آن به معنای فعال‌بودن API عمومی نیست. برای پیش‌نمایش آفلاین هیچ کلید یا اعتبارنامه‌ای تنظیم نکنید و هیچ کلیدی را در مخزن، فایل تست، گزارش یا گفتگو قرار ندهید.

## اجرای ایمن برای توسعه‌دهنده

پیش‌نیاز: Node.js 22. برای آزمون رابط آفلاین فقط از داده ساختگی استفاده کنید. سرویس توسعه محلی را فقط در محیط توسعه اجرا کنید:

```bash
node backend/server.js
```

سرویس روی `127.0.0.1:8787` گوش می‌دهد. آن را روی اینترنت یا از طریق reverse proxy منتشر نکنید. حتی در توسعه محلی نیز نام، شماره ملی، شماره تماس، رمز، کد یک‌بارمصرف، اسناد یا اطلاعات محرمانه موکل را وارد نکنید.

## آزمون‌ها و بررسی آمادگی انتشار

```bash
node --test tests/*.test.cjs
node scripts/check-v1-readiness.cjs --enforce
```

فرمان دوم تا تکمیل موانع باید `NOT_READY` و کد خروج ۱ بدهد؛ این شکست مورد انتظارِ دروازه انتشار است، نه شکست آزمون‌های قراردادی. آزمون مرورگر واقعی به Chromium/Chrome و متغیر `CHROME_BIN` نیاز دارد:

```bash
CHROME_BIN=/path/to/chromium node --test tests/real-browser-smoke.cjs
```

### دامنه GitHub Actions

`.github/workflows/ci.yml` روی push شاخه‌های آزمایشی مشخص، از جمله `dadyar/ai-chat-private-20261101`، آزمون خواندنی اجرا می‌کند. workflow مجوز نوشتن محتوا یا مرحله استقرار ندارد. اجرای سبز CI به‌تنهایی تأیید حقوقی، امنیت محیط انتشار یا آمادگی نسخه ۱ نیست.
