# بسته عمومی پیش‌نمایش دادیار، صرفاً برای بازبینی

این Workflow فقط روی push شاخه آزمایشی `dadyar/ai-chat-private-20261101` اجرا می‌شود و Artifact آن دقیقاً یک فایل دارد:

`public/index.html`

فایل از `dadyar-preview/index.html` با سازنده بسته آفلاین تولید می‌شود. پوشه `handoff/` شامل فراداده اپراتور، README و checksumها است و هرگز در Artifact عمومی قرار نمی‌گیرد.

## ماهیت Artifact

- این Artifact فقط برای مشاهده و بازبینی نسخه ایستای سناریوی کاملاً ساختگی چک است.
- مخزن در حال حاضر عمومی است؛ بنابراین باید فرض کرد Artifact عمومی نیز قابل دریافت است.
- فایل نباید شامل داده موکل، رمز، کلید API یا اطلاعات محرمانه باشد.
- پیش‌نمایش از API استفاده نمی‌کند؛ API و گفت‌وگوی هوشمند عمومی خاموش‌اند.
- Artifact مجوز استقرار روی `mehdisehat.ir` نیست و جایگزین Restore مستقل، احراز هویت بازبین، بررسی امنیت، اعتبارسنجی مقصد یا مجوز مالک نمی‌شود.
- Artifact فقط هفت روز نگهداری می‌شود و نام آن SHA کامل commit مبدأ را دارد.

## روش بازبینی

1. در GitHub Actions اجرای Workflow با نام **Dadyar public-only preview review artifact** را باز کنید.
2. Artifact متناظر با SHA commit موردنظر را دریافت کنید.
3. فقط محتوای HTML را در محیط محلی بازبینی کنید؛ اطلاعات واقعی وارد نکنید.
4. SHA-256 فایل دانلودشده را با مقدار `source_sha256` در لاگ مرحله ساخت همان اجرا تطبیق دهید.
5. تا وقتی همه دروازه‌های انتشار تأیید نشده‌اند، فایل را روی هاست بارگذاری نکنید.

## ممنوعیت انتشار

در هر شرایطی تا اثبات بازیابی بکاپ در Sandbox جداگانه و اعتبارسنجی مقصد، این Artifact صرفاً بسته بازبینی است. هیچ فایل، DNS، دیتابیس یا مسیر تولید با این Workflow تغییر نمی‌کند.
