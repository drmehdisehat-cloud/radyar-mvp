# مرز HTTP دریافت گزارش پس از بازبینی امضاشده

**وضعیت: نمونه آزمایشیِ جدا از سرور؛ هنوز route فعال یا منتشر نشده است.**

فایل `backend/review-release-http-handler.cjs` یک adapter محدود HTTP/1 برای دریافت گزارش از یک تابع دروازه سمت سرور فراهم می‌کند. این فایل عمداً در `backend/server.js` ثبت یا mount نشده است؛ پیش‌نمایش استاتیک `dadyar-preview/index.html` نیز هیچ درخواستی به این route ارسال نمی‌کند.

## قرارداد

- فقط `POST /api/dadyar/review-report` با Origin دقیق HTTPS پیکربندی‌شده پذیرفته می‌شود؛ Host درخواست نیز باید پس از نرمال‌سازی URL دقیقاً با host همان Origin منطبق باشد. Host غایب، نامعتبر یا متعلق به دامنه دیگر با 421 رد می‌شود.
- پشت reverse proxy فقط در صورتی قابل استفاده است که Host عمومی canonical را بدون بازنویسی به handler برساند؛ به `X-Forwarded-Host` یا سرآیندهای مشابه اعتماد نمی‌شود.
- درخواست cross-site، سرآیندهای امنیتی تکراری، مسیرهای دارای query/encoding/normalization، JSON با کلید تکراری، UTF-8 نامعتبر، بدنه فشرده و بدنه بزرگ رد می‌شوند.
- بدنه فقط یک عضو `envelope` می‌پذیرد؛ شناسه بازبین یا گزارش از بدنه درخواست دریافت نمی‌شود.
- تابع `releaseReviewedReport` درخواست واقعی و پاکت امضا را دریافت می‌کند. این تابع باید هویت بازبین را از نشست سمت سرور احراز کند، استقلال بازبین را بررسی کند، امضای متصل به commit و Artifact را اعتبارسنجی کند، nonce را به‌صورت بادوام و اتمیک مصرف کند و گزارش را از مخزن سمت سرور بارگذاری کند.
- فقط بایت‌های گزارش بارگذاری‌شده سمت سرور، با محدودیت اندازه و سرآیندهای no-store/nosniff/same-origin بازگردانده می‌شوند.
- سرور نمونه دارای محدودیت اندازه header و timeoutهای درخواست، header و keep-alive است.

## محدودیت و شروط استفاده

این adapter **احراز هویت، trust registry، nonce store، storage loader، TLS، CSRF/session integration یا مجوز انتشار را فراهم نمی‌کند**. تست‌ها از نشانگر نشست و داده ساختگی استفاده می‌کنند و صرفاً مرز HTTP و قرارداد تزریق وابستگی را می‌آزمایند. این نشانگر، احراز هویت واقعی نیست.

برای استفاده واقعی باید یک پیاده‌سازی مستقل و بازبینی‌شده از `releaseReviewedReport` تزریق شود. تا پیش از تأمین IdP/SSO، نگاشت کلید عمومی pin‌شده به هویت بازبین، سیاست استقلال، دفتر nonce تراکنشی، مخزن گزارش immutable، HTTPS و مجوز صریح مالک، این فایل نباید به هیچ سرور یا سایت متصل شود.

## آزمون

`node --test tests/review-release-http-boundary.test.cjs`

تمام آزمون‌ها با نشست، امضا و گزارش ساختگی اجرا می‌شوند. موفقیت آن‌ها به معنی فعال‌بودن API یا آماده‌بودن انتشار نیست.
