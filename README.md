# دادیار | Radyar MVP

نسخه ۰.۲، نمونه آزمایشی آفلاین مصاحبه حقوقی برای سرقت، چک و طلاق.

**محدودیت مهم:** این محصول فعلاً هوش مصنوعی، بانک قوانین معتبر، بک‌اند یا مشاوره حقوقی قابل اتکا ندارد. اطلاعات پرونده در حافظه مرورگر باقی می‌ماند. برای استفاده عمومی و داده‌های محرمانه مناسب نیست.

فایل‌های `index.html` و `app.js` را با وب‌سرور محلی اجرا کنید. پس از باز شدن صفحه، موضوع و نقش کاربر را انتخاب و به سؤالات پاسخ دهید.

گام بعدی: آزمون مرورگر واقعی، بازبینی امنیتی، سپس API و بانک قوانین مستند.
