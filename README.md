# دادیار | Radyar MVP

**وضعیت: نمونه آزمایشی، غیرقابل انتشار عمومی و غیرمجاز برای اطلاعات واقعی موکل.**

این مخزن یک رابط فارسی برای **مصاحبه و سامان‌دهی اولیه اطلاعات پرونده** است؛ نه سامانه مشاوره حقوقی قابل اتکا، نه دادگاه مجازی عملیاتی، و نه موتور هوش مصنوعی متصل به بانک قوانین رسمی. خروجی آن تشخیص قطعی عنوان دعوا، مرجع صالح، مهلت قانونی یا نتیجه پرونده نیست.

## امکانات موجود در همین مخزن

- شش موضوع فاز اول: سرقت تعزیری/زورگیری، ادعای کلاهبرداری، مطالبه وجه غیرچکی، چک، طلاق و مهریه.
- چهار نقش برای هر موضوع: خواهان/شاکی، خوانده/متهم، وکیل و شاهد؛ پرسش‌های موضوعی و خلاصه متنی قابل بازبینی و دانلود.
- رابط مرورگر و API آزمایشی **صرفاً محلی** برای اعتبارسنجی ساختاری داده‌ها؛ API فاقد احراز هویت عمومی، ذخیره‌سازی پرونده و تحلیل حقوقی هوشمند است.
- آزمون‌های قراردادی Node.js، آزمون مرورگر Chromium و GitHub Actions برای شاخه آزمایشی.

## اجرای ایمن برای توسعه‌دهنده (فقط با داده ساختگی)

پیش‌نیاز: Node.js 22. در پوشه ریشه مخزن اجرا کنید:

```bash
node backend/server.js
```

سپس در مرورگر همان دستگاه، نشانی `http://127.0.0.1:8787/` را باز کنید. سرویس عمداً فقط به `127.0.0.1` متصل می‌شود. برای مشاهده سلامت سرویس، `http://127.0.0.1:8787/health` را باز کنید. **آن را روی اینترنت، شبکه عمومی، reverse proxy یا هاست تولیدی منتشر نکنید.**

دکمه «اعتبارسنجی اختیاری با API محلی» فقط پس از تأیید کاربر، داده ساختگی را به API همان دستگاه می‌فرستد. در حالت عادی، متن مصاحبه در حافظه صفحه مرورگر نگهداری می‌شود؛ فایل گزارش دانلودشده روی دستگاه باقی می‌ماند. حتی در توسعه محلی نیز نام، شماره ملی، رمز، کد یک‌بارمصرف، اسناد یا اطلاعات محرمانه موکل را وارد نکنید.

## آزمون‌ها و بررسی آمادگی انتشار

```bash
node --test tests/*.test.cjs
node scripts/check-v1-readiness.cjs --enforce
```

فرمان دوم **باید تا تکمیل موانع انتشار، وضعیت NOT_READY و کد خروج ۱** بدهد. این شکستِ مورد انتظار، به معنی شکست آزمون‌های قراردادی نیست. آزمون مرورگر واقعی به Chromium/Chrome و متغیر `CHROME_BIN` نیاز دارد:

```bash
CHROME_BIN=/path/to/chromium node --test tests/real-browser-smoke.cjs
```

GitHub Actions در `.github/workflows/ci.yml` روی push شاخه آزمایشی `dadyar/mvp-sync-028` و روی pull requestهای هدف‌گرفته به `main` یا همین شاخه، فقط آزمون‌های خواندنی و بدون استقرار اجرا می‌کند. اجرای واقعی رویداد pull request باید جداگانه تأیید شود؛ سبز شدن CI **تأیید حقوقی، امنیت محیط انتشار یا آمادگی نسخه ۱ نیست**.

## مسیر انتشار نسخه ۱

چک‌لیست مرجع: [docs/V1-RELEASE-GATES.md](docs/V1-RELEASE-GATES.md). انتقال و تطبیق نسخه محلی واقعی، آزمون امنیت در محیط staging، احراز هویت، حریم خصوصی و نگهداری داده، تطبیق قوانین رسمی با تاریخ اعتبار و تأیید حقوقی انسانی، و سپس اجازه صریح مالک و پشتیبان‌گیری ضروری‌اند.

**هیچ تغییری در `main` یا سایت زنده بدون تأیید و پشتیبان اعمال نشود.** شماره‌های نسخه درج‌شده در رابط یا endpoint سلامت، اثبات همسانی با نسخه محلی، انتشار یا پیشرفت محصول نیستند.
