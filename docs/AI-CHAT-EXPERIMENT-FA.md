# اتصال آزمایشی پاسخ‌گوی دادیار

این تغییر روی شاخه آزمایشی است؛ انتشار عمومی یا تأیید صحت حقوقی نیست. ورود اصلی `/chat.html` روی همان سرور محلی `backend/server.js` است. API در `/api/chat` فقط با Bearer معتبر و تأیید داده ساختگی پاسخ می‌دهد. بدون پیکربندی، خطای ۵۰۳ می‌دهد. سرور همچنان loopback-only است و محیط production/staging را رد می‌کند.

متغیرهای خصوصی: `OPENAI_API_KEY`، `DADYAR_PREVIEW_TOKEN` (۳۲ بایت تصادفی با base64url بدون padding)، و اختیاری `OPENAI_MODEL` (پیش‌فرض `gpt-4.1-mini`). کلید و کد دسترسی نباید در مخزن، URL، HTML یا لاگ قرار گیرند. کد دسترسی آزمایش با کلید API متفاوت است. برای اجرای محلی، متغیرها را از فایل خصوصی تأییدشده خارج مخزن وارد محیط پردازش کنید و `node backend/server.js` را اجرا کنید.

حدود: ۳۰ فراخوانی در روز برای هر پردازش، دو درخواست همزمان، حداکثر ۱۲ پیام و ۱۲هزار نویسه گفتگو، خروجی ۹۰۰ توکن و مهلت ۴۵ ثانیه. شمارنده با restart پاک می‌شود؛ سقف هزینه پایدار یا احراز هویت تولیدی نیست. برای انتشار، TLS، حساب کاربری/جلسه، محدودسازی پایدار و سقف هزینه در درگاه مستقل لازم است. سرور محلی فعلی را پشت reverse proxy عمومی نکنید.

متن گفتگو فقط در حافظه مرورگر و هنگام پاسخ در پردازش سرور است؛ برنامه پرونده را ذخیره نمی‌کند. متن به OpenAI ارسال می‌شود؛ `store:false` به معنی تضمین عدم نگهداری در همه لایه‌های ارائه‌دهنده نیست. هیچ مدرک یا پرونده واقعی مجاز نیست. خروجی با textContent نمایش داده می‌شود. تاریخچه، کلید و خطای خام ارائه‌دهنده لاگ نمی‌شوند. بانک قوانین رسمی، صوت، بازیابی منابع و اختیار قضایی پیاده نشده‌اند.

برای ایران‌هاست اجرای Node.js هنوز باید تأیید شود؛ این کد قابل کپی مستقیم به public_html نیست. هیچ کلیدی برای استقرار به هاست منتقل نشده است.

## نتیجه بررسی ۱ نوامبر ۲۰۲۶

۳۶۵ آزمون Node موفق شد (شامل چهار آزمون جدید اتصال، مرز نقش، تأیید داده ساختگی، احراز هویت و سقف درخواست). بررسی syntax و whitespace موفق بود. دسترسی واقعی `/v1/models` پاسخ ۲۰۰ داد؛ فراخوانی تولید پاسخ با مدل پیش‌فرض خطای HTTP 429، کد `credit_balance_exhausted` و نوع `insufficient_quota` داد. بنابراین دریافت پاسخ واقعی موفق نشده و ادعای فعال‌شدن پاسخ‌گوی سایت نداریم. رفع مانع به شارژ اعتبار API توسط مالک نیاز دارد. هیچ اطلاعات واقعی برای آزمون ارسال نشده است.
