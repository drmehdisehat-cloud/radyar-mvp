# Dadyar MVP security boundary

This repository contains an experimental legal intake UI. Do not enter real client identities, documents, or confidential case facts.

The separately packaged development API is loopback-only, stateless, and not production-ready. It must not be publicly deployed until authentication, TLS, secure persistence decisions, access control, retention policies, and security testing are implemented and reviewed.

Current local development packages are not automatically synchronized with this repository. GitHub Actions can only verify files actually committed here. A local test result does not prove deployment to radyar.ir.

This document is not a claim that these controls have been implemented.
