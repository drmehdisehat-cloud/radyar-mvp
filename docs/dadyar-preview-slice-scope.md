# دامنه برش پیش‌نمایش دادیار

این برش فقط کارگاه آفلاینِ چک ساختگی را بسته‌بندی می‌کند.

## داخل دامنه
- پرسش آزاد فارسی و طبقه‌بندی محلیِ چندموضوعی با ۲۷ سرنخ؛
- تحلیل فقط بخش چک فرضی؛ موضوعات دیگر صرفاً سرنخ‌اند و پاسخ تولید نمی‌شود؛
- ثبت چک‌لیست و اظهار بازبین محلی، سپس دریافت گزارش ساختگی؛
- آزمون Chromium در viewport باریک و شبیه‌سازی دستگاه موبایل؛
- مسیر HTTP آزمایشی `/dadyar-preview/` و نبود درخواست API یا ذخیره‌سازی مرورگر؛
- probe فقط‌خواندنی HTTPS برای تطبیق دو فایل Artifact و هدرهای امنیتی staging، بدون ارسال credential یا عملیات نوشتنی.

## خارج از دامنه
- محاسبه خسارت تأخیر تأدیه و هر ابزار مستقل دیگر؛
- شاخص‌های رونویسی‌شده از تصویر مالک، تا زمان دریافت سند رسمی، تطبیق بایت خام، هش و بازبینی حقوقی مستقل؛
- احراز هویت واقعی بازبین، Restore بکاپ، مقصد هاست و استقرار.

## مرز انتشار
این بسته فقط Artifact بازبینی است، نه انتشار سایت. ثبت بازبینی در صفحه محلی است و هویت/استقلال شخص را احراز نمی‌کند. منابع حقوقی تأییدشده در این برش صفر است؛ بنابراین نتیجه حقوقی قطعی تولید نمی‌شود. API و گفت‌وگوی هوشمند عمومی خاموش می‌مانند.

## کنترل یکپارچگی
آزمون قراردادی، هش SHA-256 بلوک inline script و style را با Node.js و مقدار CSP تطبیق می‌دهد. فایل Artifact فقط صفحه پیش‌نمایش و Manifest آن است.

## شرط پذیرش CI
هر Artifact بازبینی باید از همان SHA سرشاخه PR ساخته شود؛ سبز بودن CI روی SHA قبلی یا merge-ref موقت کافی نیست. Manifest باید SHA منبع و SHA workflow را جداگانه ثبت کند و Git Blob هر دو با درخت منبع بررسی شود. شکست هر آزمون موبایل، CSP یا مرز آفلاین، ساخت/آپلود Artifact را متوقف می‌کند.
